1. Data yang Kami Kumpulkan

Kami mengumpulkan data minimum yang diperlukan untuk mengoperasikan layanan otomasi konten Blogger Anda: alamat email, nama lengkap, daftar blog Google Blogger yang Anda otorisasikan secara eksplisit, draf artikel, bank keyword, serta catatan aktivitas sistem (Audit Log).

2. Penggunaan Google API & Kepatuhan Limited Use

Blogger Autopilot menggunakan Google Blogger API v3 (scope https://www.googleapis.com/auth/blogger) secara eksklusif untuk membaca daftar blog Anda, menyinkronkan postingan, serta membuat atau memperbarui draf/postingan atas instruksi Anda.

Penggunaan dan transfer informasi yang diterima dari Google API oleh Blogger Autopilot mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use. Kami tidak pernah menjual data Google Anda, tidak menayangkan iklan berbasis data Google Anda, dan tidak mengizinkan pihak ketiga mengakses token OAuth Anda.

3. Enkripsi & Keamanan Kredensial

Seluruh OAuth Refresh Token Google disimpan dalam bentuk terenkripsi (simetris AES/Fernet) di database terisolasi per penyewa (multi-tenant). Kata sandi akun di-hash menggunakan bcrypt. Anda dapat mencabut akses Google kapan saja melalui halaman Keamanan Akun Google atau menghapus blog dari dashboard.

4. Pembayaran & Pihak Ketiga

Pembayaran langganan Rupiah (QRIS, Virtual Account Bank, E-Wallet) diproses melalui mitra payment gateway resmi Midtrans. Kami tidak menyimpan nomor kartu kredit atau PIN e-wallet Anda di server kami.

5. Hak Penghapusan Data & Kontak

Anda berhak mengekspor data Anda (Backup 1-Klik) maupun meminta penghapusan akun beserta seluruh data terkait dengan menghubungi tim dukungan kami di support@bloggerautopilot.id.
