## 2. Prinsip Dasar SEO (Standar E-E-A-T)
- Search Intent: Artikel harus langsung menjawab kebutuhan pencarian pengguna tanpa bertele-tele.
- Struktur Heading: H1 (Judul utama), H2 (Sub-topik penting), H3 (Rincian/Langkah teknis).
- On-Page SEO: Target primary keyword muncul alami di judul, paragraf pembuka (100 kata pertama), dan minimal 1 sub-heading.
- Format Konten: Rapi, menggunakan poin-poin/list, code snippet jika relevan, dan penjelasan konsep yang mudah dipahami.
